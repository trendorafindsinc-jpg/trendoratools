# Trendora Tools v1.2 (Offline PWA + Android)

Practical financial tools from **Trendora**, under **LUCIA**.

## Brand
- Mark: violet → cyan rounded tile with a white **T** and cyan accent.
- Icons live under `public/icons/` and `public/brand/trendora-mark.svg`.
- Run `npm run icons` (or `npm install`) to materialize all PNG sizes from the embedded installer.

## What's included
- Full offline PWA — install to home screen on Android & iPhone
- Capacitor Android project for native APK (Termux-friendly build script)
- Expenses, Income, Budget, Bills, Savings, Debts and Reports
- Command Center dashboard, Insights, Legal suite, Settings (sign-in / sign-out)

### Android (Chrome)
1. Open the live site → menu → **Install app**
2. Home-screen icon uses the Trendora mark (192 / 512 + maskable)

### iPhone (Safari)
Share → **Add to Home Screen** (apple-touch-icon 180px)

## Android APK on Termux (Samsung S10+)

Space and RAM are limited on S10+. Prefer **debug APK** and a lean SDK.

### One-time setup
```bash
pkg update
pkg install nodejs-lts openjdk-17 git wget unzip
# Install Android command-line tools into $HOME/android-sdk (platform-34 + build-tools 34.0.0)
export ANDROID_HOME=$HOME/android-sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools
sdkmanager "platforms;android-34" "build-tools;34.0.0" "platform-tools"
```

### Build
```bash
git clone https://github.com/trendorafindsinc-jpg/trendoratools.git
cd trendoratools
git checkout feature/brand-icons-capacitor-android   # or main after merge
npm install
npm run android:build
```

The script will: install icons → `vite` build → `cap add android` (first time) → `cap sync` → copy mipmaps → `./gradlew assembleDebug`.

APK path: `android/app/build/outputs/apk/debug/app-debug.apk`

Install on device: open the APK file, or `adb install -r …`.

### Notes for S10+ / Termux
- Use OpenJDK 17 (not 21) for broader Gradle compatibility.
- Prefer `--no-daemon` (already in the script) to save RAM.
- If Gradle OOM: `export GRADLE_OPTS="-Xmx1024m"` or lower.
- Do not commit large `android/` build outputs; source is generated by Capacitor.
