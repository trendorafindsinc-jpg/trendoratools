# Design System

TrendoraTools uses a token-based design system in `src/styles/app.css`.

## Principles

- Clarity over decoration
- Calm, professional surface hierarchy
- Strong accessible contrast
- Mobile-first responsive layout
- Visible focus states
- Reusable card, form, button, list, badge, progress, and empty-state patterns

## Themes

Light, dark, and system themes are supported using CSS custom properties and `data-theme`
on the root element.

## Components

- `.card`
- `.btn`, `.btn-primary`, `.btn-secondary`, `.btn-danger`
- `.field`, `.field-label`, `.field-input`
- `.stats-grid`
- `.list-row`
- `.progress`
- `.empty-state`
- `.toast`
